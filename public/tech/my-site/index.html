這個網站本身就是一個作品。以下是技術選型與功能概覽。

技術棧 #

項目選擇
靜態生成器Hugo 0.161
主題Congo v2
CMSDecap CMS
留言Cusdis
部署Cloudflare Pages

功能 #

  • 多語系：繁體中文（預設）、英文、日文
  • 深色模式：跟隨系統自動切換
  • 目錄：長文章自動產生 TOC
  • 留言：Cusdis 輕量留言系統，深色模式同步
  • 訂閱：文章頁底嵌入 Substack 訂閱框
  • CMS：Decap CMS 提供視覺化編輯介面

原始碼 #

原始碼存放於 GitHub，透過 Cloudflare Pages 自動部署。推送至 main 觸發正式環境建置；其他分支觸發預覽環境建置。
